# AdolFlow - Portfolio Personnel 🚀

Bienvenue sur le dépôt de mon portfolio professionnel. Je suis **Jean Pierre Adolphe**, Développeur Junior Fullstack. Ce projet met en valeur mes compétences, mes projets récents et offre un moyen de me contacter.

---

## ✨ Fonctionnalités

*   🌍 **Bilingue (FR / EN)** : Système de traduction dynamique codé entièrement en JavaScript natif, permettant de changer de langue sans recharger la page.
*   📱 **100% Responsive** : Interface fluide s'adaptant parfaitement aux écrans de mobiles, tablettes et ordinateurs (utilisation de Flexbox et CSS Grid).
*   ⚡ **Single Page Application (SPA)** : Navigation fluide entre les sections (À propos, Compétences, Projets, Contact) gérée dynamiquement avec JavaScript.
*   ✉️ **Formulaire de Contact Fonctionnel** : Intégration d'une solution d'envoi d'emails sans backend, permettant aux visiteurs de me contacter directement.
*   📄 **Consultation de CV** : Visualisation directe du CV au format PDF via un nouvel onglet.

---

## 🛠️ Technologies Utilisées

Ce projet a été conçu sans framework lourd, afin de démontrer ma maîtrise des fondations du web :

*   **HTML5** : Structure sémantique claire.
*   **CSS3** : Animations personnalisées (`@keyframes`), variables, transitions fluides.
*   **Vanilla JavaScript (ES6+)** : Manipulation du DOM, écouteurs d'événements et gestion d'objets pour les traductions.
